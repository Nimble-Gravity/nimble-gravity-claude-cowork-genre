Gen Re · Cowork Program

Optional Prep & Follow-up

Each workshop is two hours of hands-on time. A little prep beforehand and a small task afterward help it stick — but both are optional, and we cover the key parts live in each session. Do as much or as little as fits your week.

Four workshops · optional, before & after each
Workshop 1 · Setup & Foundations

Get set up before we start

Optional prep · covered in the session

Confirm you have Claude Cowork access on your machine. Complete the AI maturity poll. Optional warm-up: Anthropic Academy's "Introduction to Claude Cowork."

Optional follow-up

Finish your co-setup files if you didn't in the lab, then run one starter task and review the result. Bring a question to office hours.

Workshop 2 · Use Cowork

Bring a real task

Optional prep · covered in the session

Have a real task ready and its files in one folder — a legacy model or script to document, code to review, a process to write up. Skim Use Cases by Industry.

Optional follow-up

Run one more real task end to end, then write down the recurring part you'd turn into a skill. You'll build it in Workshop 3.

Open the Workshop 2 hub →

Workshop 3 · Build a Skill

Bring a workflow to automate

Optional prep · covered in the session

If you can, think of one repetitive workflow worth automating — ideally the one you named after Workshop 2 — and what good output looks like. Want a head start? The five lab files are on the lab page, but we'll also set them up together when breakout rooms open.

Optional follow-up

Build a skill for a real workflow of your own — start with the workflow-decomposition skill from the lab page — and bring the packaged .skill to office hours.

Workshop 4 · Govern & Roll Out

Bring your skill, and your IT partners

Optional prep · covered in the session

Bring the skill you built in Workshop 3. Invite your IT and compliance partners — the governance half of this session is for them.

Optional follow-up

Finalize the one-page rollout and governance plan and share it with your sponsor. Office hours continue as champions take it forward.
